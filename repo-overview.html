Topics by depth

Eight Dimensions of AI Engineering

This curriculum was designed to give engineers solid grounding across the full spectrum of Claude API usage — not just one niche. Participants leave capable of making informed decisions in each area.

  • API Integration — raw SDK usage, tool-call loops, streaming
  • Evaluation — test suites, graders, benchmark harnesses
  • Inference Optimization — model selection, cost modeling, caching
  • Context Engineering — rot mitigation, long-context strategies
  • Agentic Design — multi-agent orchestration, diagnosis
  • Full-Stack Development — Vue 3 + FastAPI with Claude Code
  • Prompt Engineering — systematic debugging and eval-driven fixing
  • Claude Code — agents, hooks, MCP, commands

Getting Started

Setup in minutes

Three execution paths supported — GitHub Codespaces, VS Code, or local. All exercises require an Anthropic API key.

1

Clone the Repository

Download the materials or open directly in GitHub Codespaces — no local install required for notebook exercises.

# Clone locally git clone <repo-url> && cd Basecamp-Exercises # Or open in GitHub Codespaces — click "Code → Open with Codespaces"
2

Set Your Anthropic API Key

Required for all notebook exercises and Claude API calls. Add to your shell profile for persistence.

# Temporary (current session) export ANTHROPIC_API_KEY=sk-ant-... # Or add to ~/.zshrc / ~/.bashrc for persistence
3A

Run the Inventory Management App

Start both the Vue 3 frontend (port 3000) and FastAPI backend (port 8001) with a single script, or bring them up individually.

# One-command startup (macOS/Linux) ./scripts/start.sh # Manual — frontend cd client && npm install && npm run dev # Manual — backend cd server && uv venv && uv sync && uv run python main.py
3B

Open a Notebook Exercise

Navigate to any session directory and open the .ipynb file. Run cells sequentially with Shift+Enter.

# Example — Day 1 developer platform exercise cd day1/02_developer-platform jupyter notebook # or open in VS Code
4

Run the Test Suite

Verify the backend is healthy. All three test modules should pass in under a second.

cd day1/01_inventory-management/tests uv run pytest backend/ -v PASSED test_inventory.py · test_orders.py · test_api.py ✓ 3 passed in 0.42s
