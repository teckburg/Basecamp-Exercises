Curriculum
Training Sessions

Eight progressive exercises, organized across two days. Each session builds on the previous and targets a distinct aspect of production AI engineering.

Day 1

Foundation — Building with Claude

01

Inventory Management System

Build-along workshop using a full-stack Vue 3 + FastAPI app as the live canvas. Covers component authoring, API design, mock data, tests, and Claude Code workflows including custom agents and hooks.

Full-Stack
02

Developer Platform — Agentic Loops

Jupyter notebook that teaches raw Claude API usage: tool definitions, multi-turn conversations, and building a support-ticket triage agent with structured tool calls and result injection.

Notebook
03

Prompt Rescue — Debugging & Evaluation

Systematic prompt debugging workflow. Students receive real failing prompts, diagnose root causes using an eval harness, apply fixes, and re-measure output quality with before/after comparisons.

Notebook
04

Diagnosing AI Problems — Multi-Agent Analysis

No-code diagnostic exercise. Students receive a client email, 4-agent system prompts, tool schemas, and execution traces — then identify architecture flaws and recommend fixes without running any code.

Analysis
Day 2

Advanced — Optimization & Production Agents

01

Building Evals — Test Suites for AI Agents

Learn to define task sets, write graders (exact match, LLM-as-judge, regex), and build an eval harness that runs Claude against a benchmark to produce quality scores for iterative improvement.

Notebook
02

Inference Optimization — Model Benchmarking

Side-by-side benchmark of Haiku, Sonnet, and Opus on TTFT, TTC, output tokens/sec, and cost. Also measures prompt caching impact. Produces a data-driven model selection framework.

Notebook
03

Context Engineering — Fighting Context Rot

Replicates Chroma's "context rot" research with needle-in-haystack tests and word faithfulness benchmarks. Compares Claude vs GPT-4.1 baselines and teaches mitigation strategies.

Notebook
04

Agent Build Hackathon — RFP Response Agent

Capstone challenge: design and implement a production-grade RFP parsing and response generation agent with knowledge-base retrieval. Facilitator dry-run scripts and expected outputs included.

Getting Started
Setup Instructions

Three ways to run these exercises — choose the one that fits your environment.

1

Clone the Repository

Download the materials to your local machine or open in GitHub Codespaces.

git clone <repo-url> cd Basecamp-Exercises
2

Set Your Anthropic API Key

Required for all notebook exercises and Claude API interactions.

export ANTHROPIC_API_KEY=sk-ant-...
3a

Run the Inventory Management App

Start both frontend and backend servers with one command (macOS/Linux).

# Option A — one command ./scripts/start.sh # Option B — manually cd day1/01_inventory-management/client && npm install && npm run dev cd day1/01_inventory-management/server && uv venv && uv sync && uv run python main.py
3b

Open a Notebook Exercise

Notebook exercises run in Codespaces, VS Code, or local Jupyter. Open the .ipynb file and run cells with Shift+Enter.

cd day1/02_developer-platform jupyter notebook # or open in VS Code
4

Run the Test Suite

Verify the backend is working correctly with the pytest suite.

cd day1/01_inventory-management/tests uv run pytest backend/ -v
